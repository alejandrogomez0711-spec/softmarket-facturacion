# SoftMarket - Modulo de Facturacion

Proyecto de refactorizacion del modulo de facturacion de SoftMarket S.A.

## Estructura
- `antes_facturacion.py`: codigo legado (con problemas).
- `softmarket/`: codigo refactorizado aplicando SOLID.
- `main.py`: ejemplo de uso.
- `test_*.py`: pruebas unitarias.

## Como ejecutar
```
python main.py
python -m unittest discover -v
```
